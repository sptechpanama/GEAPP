# Páginas heredadas

Esta carpeta conserva temporalmente páginas retiradas de la navegación de
Streamlit. No se elimina su código mientras se completa el periodo de
validación de la página canónica.

- `panama_compra2_0.py`: antigua variante de validación. La página oficial es
  `pages/panama_compra.py`; el detector reutilizable continúa disponible en
  `services/panama_compra_detection_v2.py`.

Los archivos dentro de `legacy_pages` no son descubiertos automáticamente por
Streamlit como páginas de navegación.
